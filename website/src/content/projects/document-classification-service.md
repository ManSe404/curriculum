Built an end-to-end document processing service covering extraction, classification, and
structured storage, running as containerized microservices on Azure for scalable intake.

Automating categorization cut the manual tagging effort substantially, and — the less
obvious win — made labeling consistent. Human taggers drift over time and disagree with
each other; a model applies the same taxonomy the same way every time.
